# Security Policy

## Supported Versions

We are currently providing security updates for the following versions:


| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it using the following steps:

1. Navigate to the **[Security]** tab of this repository.
2. Select **[Advisories]** from the left-hand sidebar.
3. Click the **[Report a vulnerability]** button to submit your report.

We will review your report privately and respond as soon as possible. Please avoid reporting vulnerabilities through public Issues or Pull Requests to prevent potential exploitation before a fix is available.

# Security Policy

## Supported Versions

現在、以下のバージョンに対してセキュリティアップデートを提供しています。


| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

脆弱性を見つけた場合は、以下の手順で報告をお願いします。

1. GitHub リポジトリの **[Security]** タブに移動します。
2. 左側のメニューから **[Advisories]** を選択します。
3. **[Report a vulnerability]** ボタンをクリックして詳細を入力してください。

報告いただいた内容は非公開で確認し、修正が必要な場合は速やかに対応します。パブリックな Issue やプルリクエストでの直接的な脆弱性報告は、悪用を避けるため控えていただけると助かります。
